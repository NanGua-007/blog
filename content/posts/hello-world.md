## 欢迎来到我的博客

这是一篇示例文章。博客使用 **Next.js** 搭建，支持 Markdown 写作和 Giscus 动态评论。

### 功能特点

- **静态生成**：所有页面在构建时预渲染，加载飞快
- **Markdown 写作**：用熟悉的 Markdown 语法写文章
- **动态评论**：通过 Giscus + GitHub Discussions 驱动，无需自建数据库
- **免费部署**：Vercel + GitHub 全免费方案

### 代码示例

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```
